What it is

Plain-language in, a shortlist you can act on out.

Grant prospecting is slow, and the commercial databases that speed it up cost money most small nonprofits don't have — while still missing the Latino-serving funders and local community-foundation funds that never surface in a generic index.

Grant Finder is a plugin for Claude. Describe your organization in ordinary words, and it searches real public data — IRS tax filings, the federal grants.gov register, and the live web — then returns a ranked shortlist with eligibility, grant size, and a deadline it has actually checked.

One conversation serves two kinds of organization: nonprofits in the US serving Hispanic and Latino communities, and organizations based in Latin America looking for US-origin funding that reaches their country. The plugin figures out which you are from your location, and reshapes itself accordingly.

The whole design turns on one rule: never present a number, a date, or an eligibility claim it hasn't confirmed against a primary source.

How it works

Three sources, each answering a different question — merged into one list.

No single dataset can answer "which grants should we go after." Each source below is good at exactly one thing, and weak at the others. The plugin plays them to their strengths and reconciles the results by organization name.

Source 01

IRS Form 990

Every US nonprofit's public tax filing. Answers: is this a real, adequately-resourced funder? — revenue, assets, grants paid. Reached free via the ProPublica API.

Source 02

Live web search

Answers the thing tax filings can't: is it open right now, and what's the deadline? Checks the funder's or agency's own page at the moment you ask.

Source 03

Federal grants

Open opportunities on grants.gov, via a hosted server I built and deployed that wraps the government's Simpler Grants API — structured search, not scraping.

990  +  web  +  federal  →  one ranked, de-duplicated shortlist

if location = United States

Full domestic pipeline

Foundation discovery through 990s and peer organizations, federal search with pass-through tracing, plus an optional Census section — real Hispanic/Latino population and poverty figures for the grant narrative.

if location = Latin America

US-origin funding that reaches the region

Retargets to the Inter-American Foundation, per-embassy State Department programs, and US foundations with Latin America portfolios — and adds a dedicated check that a program actually reaches the org's specific country.

The pipeline · step by step

What happens between your description and the shortlist.

01

Collect five facts

Mission, location, sector, budget, size. If any is vague, it asks rather than guessing — a wrong guess silently narrows out good matches. Location sets the US-vs-Latin-America branch.

02

Find and size funders in the 990 data

Searches tax filings for grant-making foundations and confirms each is real and well-resourced — with a check that the filing isn't years stale, which would suggest a defunct funder.

03

Discover funders through peer organizations

Since no dataset says "who funded this org," it finds similar nonprofits and reads their public funder lists. A foundation backing several peers is a stronger lead than a keyword match. US orgs only

04

Search federal grants — with pass-through tracing

Queries the live server. When federal money only reaches nonprofits through a state agency, it traces one hop down to name the agency you'd actually apply to — not a dead-end "this passes through your state."

05

Verify geography precisely

For Latin-America-based orgs, confirms a funder's "Latin America program" truly covers the org's country and city. In testing this caught a program secretly limited to six Mexican states. Latin America orgs

06

Rank, and say what you can't confirm

Scores every candidate on mission, geography, size, and focus; drops poor fits rather than padding to a target count. Deadlines come back as a confirmed date, Rolling, Invitation only, or Not stated — never invented.

Field notes

The interesting part wasn't the happy path.

Wiring up an API that behaves is easy. The judgment shows in what happens when real, public, government data sources misbehave — and they did, constantly. A sample of what was found by testing and written down so it wouldn't have to be rediscovered:

HTTP 404

ProPublica returns "not found" for an empty result

Zero matches came back as a 404, not an empty list — and stacking three search terms reliably triggered it. Caught by testing a nonsense query; the fix was to search broad and treat 404 as "no results, widen."

HTTP 500

The sector filter was simply broken

ProPublica's ntee[id] filter errored in every combination tried. Worked around by searching on keyword plus state and classifying results by hand.

JS SHELL

grants.gov's own pages return nothing to a fetch

The search page and its legacy detail URLs are JavaScript apps that hand back only page chrome. Exactly one URL shape is server-rendered and readable — which is why the deployed API server exists at all.

MISLEADING

A valid Census key rejected as "invalid"

The key worked in a browser but returned an "Invalid Key" page to the tool — the real cause was a User-Agent bot-block. A separate query shape returned empty; both fixed once diagnosed rather than trusted at face value.

HTTP 421

The deployed server rejected every request

Invalid Host header — traced by reading the MCP SDK source to a DNS-rebinding guard that only trusts localhost, then disabled for the hosted, server-to-server case. A breaking dependency version was caught and pinned in the same pass.

EXCLUDED

A tempting "$500K program" that didn't survive checking

It appeared across aggregator sites. The government's own listing showed a much smaller, already-closed program. It was left out rather than reported — the rule holding even when the number is attractive.

And it's honest about what it can't do: USAID returns nothing searchable, the Inter-American Foundation's own pages block automated reads, a promising aid-spending API was left unvalidated. All written down as findings — a record of what doesn't work is as truthful as one of what does.

Install & try it

Running in about a minute.

Add to Claude ↓

Downloads hispanic-latam-grants.plugin — a small file you upload in the next step. No account or key needed to try it.

In Claude Desktop → Customize → Plugins, upload the hispanic-latam-grants.plugin file.

Open a chat and describe your nonprofit in a sentence or two — mission, where you are, roughly your size.

Read back the ranked shortlist. Ask follow-ups — dig into one funder, or request a full prospecting report.

We run workforce training for Hispanic immigrants in Houston, TX — ~$400K budget, 8 staff. Find us grants we could realistically win.
Which private Latino foundations have funded food-security work in the Bay Area lately?
Open federal grants a 501(c)(3) can apply to for after-school STEM, closing in the next 90 days?
Build a profile of the Hewlett Foundation before we approach them — and does their history favor a Hispanic nonprofit?
We're a youth education nonprofit in Mexico City. What US-origin funding could reach us?

Requires the Claude desktop app on a paid plan. Federal search runs against a live hosted server; if it's asleep, the first query may take a moment to wake it, and the plugin falls back to a public-page search if it's ever unreachable — and says so in its answer.

Straight about the edges

What it deliberately doesn't do.

990 data lags 12–24 months. Good for confirming a funder's size and history; the live web is what confirms an open cycle.

The federal server is a real hosting commitment — free-tier cold starts, no built-in uptime alerting. The graceful fallback keeps the plugin working when it's down.

Latin America support surfaces only US-origin funding. There's no connector for any country's own domestic grant programs — that would need per-country scraping and localization.

It's a scoped v1. Every limitation above is written into the plugin's own docs rather than glossed over — the same honesty the tool applies to its results.
